# Ejemplo sanitizado — Jeep Wrangler 2017

Este ejemplo documenta cómo separar funciones entre chats.

## División útil

### Chat de expediente / fotos
- mantiene `PUENTE.md`;
- sincroniza fotos seleccionadas/retocadas;
- no produce campaña nueva.

### Chat de captura / Mes Patrio
- dirige sesión nueva;
- audita material capturado;
- determina si alcanza para TikTok, Reel, historias, master y post fotográfico;
- no debe sobrescribir el trabajo del expediente.

## Aprendizaje operativo

Dos chats pueden trabajar sobre la misma unidad si sus responsabilidades están claramente separadas y ambos leen la versión vigente antes de escribir.

## Regla reutilizable

Antes de abrir otro chat pregunta:

`¿Este chat mantiene expediente, produce derivados, publica/mide o analiza?`

Si la respuesta mezcla varias funciones pesadas, conviene dividir el trabajo.

Los datos técnicos específicos deben consultarse en el `PUENTE.md` privado del vehículo.
