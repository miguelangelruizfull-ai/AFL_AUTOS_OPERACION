# Prompt base — Producir redes

Antes de producir:

1. leer `PUENTE.md` vigente del vehículo;
2. leer `AFL_AUTOS_CONTENT_SYSTEM/START_HERE.md` y `STATUS_RULES.md`;
3. para piezas gráficas consultar OBLIGATORIAMENTE, en este orden:
   - `docs/EVIDENCE_AND_PUBLICATION_RULES.md`;
   - `docs/BRAND_ASSETS.md`;
   - `formats/FLYERS_PORTADAS.md`;
   - `formats/FLYER_ENGINE.md`;
   - `formats/FLYER_FAMILIES.md`;
   - `library/flyer_audit/COMMON_ERRORS.md`;
   - `library/flyer_audit/POSITIVE_REFERENCES.md`;
   - campaña/moodboard vigente cuando aplique;
4. para TikTok, consultar el Motor Editorial vigente cuando exista.

## Gate visual obligatorio para flyers, portadas e historias

Antes de declarar una pieza `PRODUCIDO`, comprobar explícitamente:

- HERO inequívoco y dominante;
- foto fuente suficientemente limpia para la familia elegida; si el fondo real distrae, cambiar de foto o usar recorte limpio sin alterar físicamente la unidad;
- un solo tratamiento de marca/logo oficial, sin repetición innecesaria;
- título/modelo compacto y subordinado al HERO;
- 2–4 datos como máximo y solo si son publicables;
- CTA único, corto y subordinado a vehículo/modelo;
- ausencia de fondo, ornamentos, franjas o texto que compitan con la unidad;
- lectura correcta a tamaño aproximado de pantalla de teléfono;
- comparación contra `COMMON_ERRORS.md` y al menos una referencia positiva compatible por familia/formato.

Si la foto disponible no permite una pieza de calidad suficiente, NO forzar un flyer final. Devolver `BLOQUEADO_POR_FOTO / REQUIERE_MEJOR_HERO` o proponer una composición distinta.

La palabra `premium` no es una familia visual ni justifica una composición. El resultado debe demostrar la jerarquía y limpieza del Motor Visual.

Trabajar por etapas para no bloquear el chat:

A. verificar fotos/videos seleccionados;
B. producir Facebook Reel y TikTok adaptados por red;
C. producir flyer feed, flyer historia, portadas e historias;
D. redactar copies específicos;
E. subir derivados, verificar y actualizar `PUENTE.md`.

No usar VIN, odómetro, precio no autorizado ni datos pendientes. No alterar físicamente el vehículo. Foto real protagonista; máximo cuatro datos clave en flyers.

No publicar automáticamente.

Estado máximo sin confirmación de Miguel:

`PRODUCIDO / SUBIDO_A_DRIVE / PENDIENTE_APROBACION_MIGUEL`.

Si Miguel rechaza una pieza, registrar `RECHAZADO_POR_MIGUEL / NO_PUBLICAR / REQUIERE_REDISENO` y conservarla solo como trazabilidad, nunca como referencia positiva.
