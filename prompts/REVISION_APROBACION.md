# Prompt base — Revisión / aprobación

Objetivo: revisar un paquete producido sin convertir producción, subida o revisión en aprobación automática.

Antes de actuar:

1. leer `PUENTE.md` vigente;
2. verificar fuentes creativas vigentes en `AFL_AUTOS_CONTENT_SYSTEM`;
3. revisar archivos realmente producidos/subidos;
4. comprobar datos publicables y evidencia visual;
5. detectar contradicciones, errores de texto, identidad o estado;
6. proponer correcciones concretas;
7. solo registrar `APROBADO` cuando exista confirmación real de Miguel.

Mantener:

`PRODUCIDO ≠ SUBIDO ≠ APROBADO ≠ PROGRAMADO ≠ PUBLICADO ≠ MEDIDO`

No publicar automáticamente.
