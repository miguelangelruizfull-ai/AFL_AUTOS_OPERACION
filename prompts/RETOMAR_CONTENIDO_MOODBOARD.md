# AFL AUTOS — RETOMAR CONTENIDO / MOODBOARD

Usa este prompt en un chat nuevo cuando quieras retomar una unidad o una producción visual.

---

ROOT ABRIR AFL AUTOS — RETOMAR CONTENIDO

VEHICLE_ID: <PONER_ID_SI_LO_SABES>

Inicializa ROOT_ECOSISTEMA y resuelve la unidad desde fuentes vigentes. No uses memoria del chat como autoridad.

Lee en este orden:
1. Vehiculos/index/EXPEDIENTES_INDEX.json;
2. PUENTE.md vigente de la unidad;
3. AFL_AUTOS_CONTENT_SYSTEM/runtime/CONTENT_RUNTIME.md;
4. AFL_AUTOS_CONTENT_SYSTEM/library/moodboards/AFL_AUTOS_MOODBOARD_SYSTEM_V1.md;
5. material real vigente en Drive;
6. producción/experimentos activos de esa unidad;
7. Content Lab solo si hace falta pulso experimental;
8. tendencias actuales de plataforma si aportan.

Objetivo:
continuar exactamente desde el estado vigente y producir mejor, no empezar de cero.

Antes de producir:
- indicar estado actual;
- qué ya está aprobado/programado/publicado/medido;
- material disponible;
- bloqueos;
- qué moodboard/subdirección aplica y por qué;
- si el moodboard base NO aplica tal cual, decir por qué y crear una derivación específica.

Aprendizaje:
- una pieza aprobada = evidencia de calidad para esa pieza;
- una pieza medida = resultado observable;
- un patrón de ventas solo se considera candidato cuando se repite y existe relación comercial corroborable;
- no convertir una sola aprobación, vista o venta en regla universal.

Después mostrar el menú contextual del vehículo y RECOMENDADO AHORA.

Navegación:
ACCION → VEHICULO → INVENTARIO/NUEVO VEHICULO → AFL AUTOS → ROOT GLOBAL.
