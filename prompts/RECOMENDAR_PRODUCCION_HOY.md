# AFL AUTOS — RECOMENDAR PRODUCCION HOY

Objetivo: proponer qué contenido conviene producir hoy para aumentar conversación, visitas y ventas sin repetir piezas por rutina.

## Entrada mínima

Puede ejecutarse con:

- inventario/JSON privado disponible;
- PUENTEs vigentes de las unidades candidatas;
- material real existente en Drive;
- resultados recientes cuando existan;
- pedido o restricción de Miguel.

Miguel no necesita llegar con un formato decidido.

## Proceso

1. Identificar unidades disponibles o pendientes de confirmación.
2. Leer `PUENTE.md` vigente de las candidatas antes de usar datos variables.
3. Revisar qué material útil ya existe y clasificarlo:
   - `REUTILIZABLE`;
   - `NO_UTIL`;
   - `REQUIERE_NUEVA_CAPTURA`.
4. Revisar recencia/frecuencia de contenido cuando haya registro suficiente: evitar repetir sin motivo la misma unidad, formato o intención.
5. Revisar resultados medidos recientes cuando existan, separando rendimiento de plataforma de resultado comercial.
6. Si existe acceso web y aporta valor, hacer pulso del día con fuentes actuales verificables como:
   - TikTok Creative Center / Top Ads / señales de formato;
   - Google Trends México;
   - señales actuales de audio/edición/plataforma relevantes.
7. No usar una tendencia solo porque es popular. Debe poder conectarse con el objetivo comercial y el material real.
8. Proponer máximo 3 acciones priorizadas por utilidad operativa, no por una puntuación abstracta.

## Salida obligatoria por propuesta

Para cada acción indicar:

- vehículo(s);
- formato/canal;
- objetivo principal;
- idea/hook resumido;
- material a reutilizar o captura mínima necesaria;
- gate pendiente: precio / teléfono / CTA / duración;
- motivo comercial;
- qué medir después.

## Familias disponibles

- `FLYER`;
- `TIKTOK_REEL`;
- `POST_HISTORIA`;
- `WHATSAPP`;
- `PAQUETE`.

Puede combinar formatos cuando una sola sesión o activo real lo soporte.

## Reutilización

`REUTILIZAR MATERIAL != REPETIR PIEZA`

Una sesión existente puede generar una pieza nueva cambiando de forma justificada:

- selección de tomas;
- hook;
- narrativa;
- formato;
- copy;
- audio;
- CTA;
- objetivo.

Si la fotografía/video fuente falla el gate, pedir `PLAN_CAPTURA_MINIMO` en vez de compensar con diseño excesivo.

## Gate comercial

Si Miguel no lo indicó y la propuesta pasa a producción resolver:

- `MOSTRAR_PRECIO = SI/NO`;
- `TELEFONO_CTA = NINGUNO/1/2/AMBOS`;
- duración audiovisual;
- posición CTA.

No inventar precio, disponibilidad, motor, versión, documentación, equipamiento ni datos técnicos.
