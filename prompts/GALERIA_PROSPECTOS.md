# Prompt base — Galería para prospectos

Regla:

`FOTOS_PARA_LEAD ≠ FOTOS_PARA_PUBLICACION`

1. Lee completo el `PUENTE.md` vigente de la unidad.
2. Revisa la selección/retocado existente; no regresar a originales salvo necesidad verificable.
3. Excluye VIN, odómetro, documentos y material sensible.
4. Elige aproximadamente 8–15 fotos útiles para un prospecto, priorizando comprensión de la unidad sobre diseño editorial.
5. Crea o reutiliza una carpeta clara en Drive sin borrar ni sobrescribir originales.
6. Devuelve enlace verificable.
7. Registra en `PUENTE.md` cuál galería para prospectos queda vigente.
8. No crear una web pública independiente por vehículo por defecto.

No inventar especificaciones a partir de las fotos.
