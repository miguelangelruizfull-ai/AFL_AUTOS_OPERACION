# Prompt base — Cierre y sincronización de chat

Objetivo: cerrar un chat sin volver a producir contenido y dejar todo reconstruible por otro chat.

1. Identificar exactamente qué se hizo en este chat.
2. Verificar los archivos/enlaces de Drive usados o creados.
3. Leer versiones vigentes de GitHub antes de actualizar.
4. Crear únicamente registros que falten; no duplicar.
5. Registrar estados reales: creado, subido, aprobado, programado, publicado, medido.
6. Registrar fechas, URLs y pendientes verificables.
7. Actualizar `PUENTE.md` o archivos de coordinación correspondientes.
8. Entregar un checkpoint corto para otro chat.

No inventar faltantes. No borrar trabajo previo. No confundir producción con publicación.
