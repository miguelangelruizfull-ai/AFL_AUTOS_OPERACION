# Prompt base — Vendido / entrega

Usar cuando Miguel confirme que una unidad se vendió o entregó.

1. Identificar la unidad contra `Vehiculos` y leer `PUENTE.md` vigente.
2. Registrar `VENDIDO/ENTREGADO` solo con confirmación explícita.
3. Conservar videos/fotos de entrega en Drive como evidencia.
4. Si se produce contenido, usar solo datos confirmados y separar `PRODUCIDO` de `PUBLICADO`.
5. No afirmar que una publicación causó la venta si la venta ocurrió antes o no existe atribución.
6. Actualizar expediente y, si el caso aporta aprendizaje creativo, registrar un caso en `AFL_AUTOS_CONTENT_SYSTEM`.

Entregar: unidad, estado comercial confirmado, evidencia, piezas producidas/publicadas, commits y medición pendiente.
