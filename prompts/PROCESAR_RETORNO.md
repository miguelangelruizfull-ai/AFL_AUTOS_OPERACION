# Prompt base — Procesar RETORNO_AL_COORDINADOR

1. Lee el retorno/checkpoint pegado como contexto auxiliar, no como fuente de verdad absoluta.
2. Identifica vehículo/proyecto, etapa ejecutada, resultado, commits, pendientes, siguiente módulo y riesgos.
3. Vuelve a consultar las fuentes vigentes antes de continuar porque pueden existir chats concurrentes.
4. Para vehículos, lee completo el `PUENTE.md` vigente.
5. Compara el retorno con el estado actual y conserva cualquier trabajo nuevo realizado después del retorno.
6. Determina el primer pendiente verificable.
7. No repitas trabajo ya confirmado.
8. Si el siguiente paso está claro y autorizado, ejecútalo; no te limites a resumir el retorno.

Un retorno coordina; no sustituye GitHub, Drive o PUENTE.md.
